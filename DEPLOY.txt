FEEL IT — COMPLETE SITE PACKAGE (all features)
==============================================

1) Unzip this folder into your GitHub repo root (Feel-IT_OFFICAL).
2) KEEP your existing files:
     assets/1.png
     assets/unnamed.png
     (and any QR / payment images you already use)
3) Commit + push all files.
4) In Supabase → SQL Editor:
     a) Run supabase-setup.sql (if not already)
     b) Run security-rls-harden.sql  ← important for security
5) Supabase → Authentication → Users → create staff user
     Email must match STAFF_EMAILS in script.js
     (admin@feelit.com or feelitofficial@gmail.com)
6) Hard refresh the live site (Ctrl+Shift+R).
